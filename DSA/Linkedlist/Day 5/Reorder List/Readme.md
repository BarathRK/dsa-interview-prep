\# Linked List 6: Reorder List



\## Pattern

Divide and Reconnect



\---



\## Problem Statement

Reorder list as:

L0 → Ln → L1 → Ln-1 → ...



\---



\## Optimal Approach

1\. Find middle  

2\. Reverse second half  

3\. Merge both halves alternately  



\---



\## Why it works

Reversing second half aligns both ends for alternating merge.



\---



\## Complexity

\- Time: O(N)  

\- Space: O(1)
