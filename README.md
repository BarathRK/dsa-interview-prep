## My Problem Solving Approach

Whenever I solve a problem, I try to follow a structured process instead of jumping directly to the final optimized code.

### Problem-solving steps I follow:

1. **Read and understand the problem statement clearly**
   Make sure I know exactly what the input, output, and goal of the problem are.

2. **Check the constraints**
   Constraints help decide whether a brute force solution is acceptable or whether optimization is necessary.

3. **Think in a rough way**
   Before writing code, I try to build an intuition for the problem and think about possible approaches.

4. **Write the brute force solution**
   I first solve the problem in the most straightforward way to ensure the logic is correct.

5. **Find time and space complexity**
   Once the brute force solution is ready, I analyze its efficiency and identify bottlenecks.

6. **Try to optimize the solution**
   Finally, I look for patterns, better data structures, or algorithmic techniques to improve the solution.
